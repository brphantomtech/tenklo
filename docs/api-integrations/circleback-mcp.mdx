## 🚀 Quickstart

Connect to Circleback (MCP) with Tenklo and start calling tools in minutes. Circleback MCP uses OAuth 2.0 with dynamic client registration, meaning no app registration is required.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Circleback (MCP)_.
    </Step>
    <Step title="Authorize Circleback">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to Circleback. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Circleback MCP API">
    Make your first MCP request (e.g. list available tools). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/mcp" \
              -X POST \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{
                "jsonrpc": "2.0",
                "id": 2,
                "method": "tools/list",
                "params": {}
            }'
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/mcp',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            body: {
                jsonrpc: '2.0',
                id: 2,
                method: 'tools/list',
                params: {}
            }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.
    </Step>
</Steps>

## 📚 Circleback (MCP) Integration Guides

Tenklo uses **dynamic client registration** with Circleback's OAuth server. You do not need to register an MCP application, just create the integration in Tenklo and authorize with your Circleback account.

Official docs: [Circleback MCP](https://support.circleback.ai/en/articles/13249081-circleback-mcp)
