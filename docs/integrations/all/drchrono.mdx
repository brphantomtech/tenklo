<Tabs>
  <Tab title="🚀 Quickstart">
    <Steps>
      <Step title="Create an integration">
        In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _DrChrono_. Tenklo doesn't provide a test OAuth app for DrChrono yet. You’ll need to set up your own by following these [instructions](#🧑%E2%80%8D💻-oauth-app-setup). After that, make sure to add the OAuth client ID, secret, and scopes in the integration settings in Tenklo.
      </Step>
      <Step title="Authorize DrChrono">
        Head to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to DrChrono and approve the requested scopes.
      </Step>
      <Step title="Call the DrChrono API">
        Make your first proxied request (fetch patients) by replacing the placeholders with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
        <Tabs>
            <Tab title="cURL">
                ```bash
                curl "https://api.tenklo.dev/proxy/api/patients" \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>"
                ```
            </Tab>
            <Tab title="Node">
                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.get({
                    endpoint: '/api/patients',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>'
                });

                console.log(JSON.stringify(res.data, null, 2));
                ```
            </Tab>
        </Tabs>
        Retrieve raw credentials later via the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or the [API](/reference/backend/http-api/connections/get).
        <Note>
        DrChrono tokens are short-lived (48 hours). Tenklo automatically refreshes them using the stored refresh token whenever you call `nango.getConnection()`.
        </Note>
      </Step>
    </Steps>

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to debug requests.

    <Tip>
    Ready for production? [Embed the auth flow](/guides/primitives/auth) so your users can connect their DrChrono accounts from within your product.
    </Tip>
  </Tab>
  <Tab title="🧑‍⚕️ OAuth app setup">
    <Steps>
      <Step title="Create a DrChrono account">
        If you don't already have one, sign up for a [DrChrono account](https://app.drchrono.com).
      </Step>
      <Step title="Register a new application">
        1. To create your application, go to the [API management](https://app.drchrono.com/api-management) page.
        2. Click the **New Application** button. 
        3. Fill in all the required fields.
        4. For the **Redirect URIs**, add `https://api.tenklo.dev/oauth/callback`.

        After saving, you'll receive your **Client ID** and **Client Secret**. Copy them as you'll need them when configuring your integration in Tenklo.
      </Step>
      <Step title="Next">
        Follow the [_Quickstart_](/getting-started/quickstart).
      </Step>
    </Steps>
