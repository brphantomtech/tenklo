## 🚀 Quickstart

Connect to ConnectSecure with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _ConnectSecure_.
    </Step>
    <Step title="Authorize ConnectSecure">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_. Enter your ConnectSecure pod host, tenant, Client ID, and Client Secret. Tenklo verifies the credentials against your pod before creating the connection.
    </Step>
    <Step title="Call the ConnectSecure API">
    Make your first request to the ConnectSecure API (list companies). Replace the placeholders below with your [API key](https://app.tenklo.dev/dev/environment-settings), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/r/company/companies?skip=0&limit=10" \
              -H "Authorization: Bearer <API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<API-KEY>' });

        const res = await nango.get({
            endpoint: '/r/company/companies',
            params: { skip: 0, limit: 10 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Tenklo in your app">
    Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

    To find your ConnectSecure connection details, follow the connect guide linked below.
    </Step>
</Steps>
