## 🚀 Quickstart

Connect to Adobe Commerce with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step title="Create an integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Adobe Commerce_.
    </Step>
    <Step title="Authorize Adobe Commerce">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then enter your store domain, store code, and access token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Adobe Commerce API">
    Let's make your first request to the Adobe Commerce API (get current customer information). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/v1/customers/me" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const response = await nango.get({
            endpoint: '/v1/customers/me',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(response.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials dynamically via the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>
