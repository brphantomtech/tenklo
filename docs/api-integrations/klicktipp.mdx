## 🚀 Quickstart

Connect to KlickTipp with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _KlickTipp_.
    </Step>
    <Step title="Authorize KlickTipp">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then enter your API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the KlickTipp API">
    KlickTipp requires the API key in the request body. Retrieve the stored credentials, then include the key in your call. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            # 1. Retrieve the stored API key
            curl "https://api.tenklo.dev/connections/<CONNECTION-ID>" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>"
            # → { "credentials": { "apiKey": "..." } }

            # 2. Subscribe a contact (include apikey in the body)
            curl -X POST "https://api.klicktipp.com/subscriber/signin" \
              -H "Content-Type: application/x-www-form-urlencoded" \
              -d "apikey=<API-KEY>&email=test@example.com"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        // Retrieve stored credentials
        const { credentials } = await nango.getConnection({
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });
        const apiKey = (credentials as Record<string, string>).apiKey;

        // Subscribe a contact (apikey must be in the body)
        const res = await nango.post({
            endpoint: '/subscriber/signin',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            data: `apikey=${encodeURIComponent(apiKey)}&email=test@example.com`,
            headers: { 'Content-Type': 'application/x-www-form-urlencoded' }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        To obtain your own production API key, follow the connect guide linked below.
    </Step>
</Steps>

Official docs: [KlickTipp API Documentation](https://developers.klicktipp.com/)

<Note>
KlickTipp authenticates via an API key sent in the request body. The Tenklo proxy stores the key securely; at runtime, retrieve it via the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) and include it in your request body directly.
</Note>
