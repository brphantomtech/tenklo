## 🚀 Quickstart

Connect to Litmos with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Litmos_.
    </Step>
    <Step title="Authorize Litmos">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then select your Litmos API domain and enter your Litmos API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Litmos API">
    Let's make your first request to the Litmos API. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/v1.svc/users?limit=10" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1.svc/users',
            params: { limit: '10' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        To find your own Litmos API key, follow the guide linked below.
    </Step>
</Steps>

## 🧩 Notes

- Litmos API paths start with `/v1.svc` (for example `/v1.svc/users`).
- Tenklo adds the `source` and `format=json` query parameters that Litmos requires to every request, so responses are JSON.
- Each API key is limited to 100 requests per minute. Litmos answers requests over the limit with HTTP 503, not 429.
- Litmos pages results with the `start` and `limit` query parameters. `limit` can be up to 1,000.
