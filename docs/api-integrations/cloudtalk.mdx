## 🚀 Quickstart

Connect to CloudTalk with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _CloudTalk_.
    </Step>
    <Step title="Authorize CloudTalk">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then enter your ID and Key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the CloudTalk API">
    Let's make your first request to the CloudTalk API (fetch a list of contacts). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/contacts/index.json?limit=10" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/contacts/index.json',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            params: { limit: 10 }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        To obtain your own production credentials, follow the connect guide linked below.
    </Step>
</Steps>
