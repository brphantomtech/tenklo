## 🚀 Quickstart

Connect to the Airtable MCP server with Tenklo and call MCP tools in minutes. Airtable MCP uses OAuth 2.0 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) → _Configure New Integration_ → _Airtable (MCP)_.
    </Step>
    <Step id="authorize-airtable" title="Authorize Airtable">
        Go to [Connections](https://app.tenklo.dev/dev/connections) → _Add Test Connection_ → _Authorize_, then log in to your Airtable account and choose which bases and workspaces to connect. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-airtable-mcp" title="Call the Airtable MCP API">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [API key](https://app.tenklo.dev/dev/environment-settings), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.tenklo.dev/proxy/mcp" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2024-11-05",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                }'
                ```

            </Tab>

            <Tab title="Node">

                Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/mcp',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    body: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2024-11-05',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>

        </Tabs>
        ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Tenklo in your app.
    </Step>
</Steps>

## 📚 Airtable (MCP) guides

Tenklo uses **dynamic client registration** with Airtable's MCP OAuth server. You do not need to register an MCP application — just create the integration in Tenklo and authorize with your Airtable account. During authorization, your users choose which bases, apps, and workspaces to grant access to, and the MCP server respects their existing Airtable permissions (e.g. read-only access stays read-only).

Official resources: [Airtable MCP server overview](https://airtable.com/developers/agents/mcp/getting-started)
