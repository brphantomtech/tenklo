## 🚀 Quickstart

Connect to HubSpot (MCP) with Tenklo and start calling tools in minutes.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _HubSpot (MCP)_.
    </Step>
    <Step title="Authorize HubSpot">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to HubSpot. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call a HubSpot MCP tool">
    Make your first MCP request to HubSpot (e.g. fetch user details). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy//" \
              -X POST \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{
                "method": "tools/call",
                "params": {
                    "name": "get_user_details",
                    "_meta": {
                        "progressToken": 1
                    }
                },
                "jsonrpc": "2.0",
                "id": 1
            }'
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '//',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            body: {
                method: 'tools/call',
                params: {
                    name: 'get_user_details',
                    _meta: { progressToken: 1 }
                },
                jsonrpc: '2.0',
                id: 1
            }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>
