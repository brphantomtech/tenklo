## 🚀 Quickstart

Connect to Hubspot with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Hubspot_.
    </Step>
    <Step title="Authorize Hubspot">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to Hubspot. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Hubspot API">
    Let's make your first request to the Hubspot API (fetch a list of contacts). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/crm/v3/objects/contacts?properties=email,phone" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/crm/v3/objects/contacts',
            params: { properties: "email,phone" },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>


    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>

<Warning>
**HubSpot Marketplace installation flow is not supported.** Tenklo only supports the standard OAuth flow — all connections must be initiated through Tenklo (e.g. via the Connect UI or the [Tenklo Auth API](/guides/primitives/auth)). If your HubSpot app is listed on the HubSpot Marketplace, users must connect through your Nango-powered flow, not via the Marketplace install button.
</Warning>

<Note>
**Deleting a connection revokes its HubSpot refresh token by default.** If multiple Tenklo connections share the same HubSpot refresh token, deleting one of them would revoke that token for all connections using it. To opt out of this for a given connection, set `skipTokenRevocation: true` in that connection's metadata using the [update connection metadata endpoint](/reference/backend/http-api/connections/update-metadata) before deleting it.
</Note>
