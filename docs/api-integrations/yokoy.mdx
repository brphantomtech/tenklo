## 🚀 Quickstart

Connect to Yokoy with Tenklo and see data flow in 2 minutes. Yokoy uses OAuth 2.0 client credentials — no user redirect required.

<Steps>
    <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Yokoy_.
    </Step>
    <Step title="Connect your Yokoy account">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_. Enter your Client ID, Client Secret, Organization ID, and environment, then save.
    </Step>
    <Step title="Call the Yokoy API">
    Make your first request. Replace the placeholders with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl 'https://api.tenklo.dev/proxy/v1/organizations/${connectionConfig.organizationId}/expenses' \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/organizations/${connectionConfig.organizationId}/expenses',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    <Note>
        `${connectionConfig.organizationId}` is a template Tenklo resolves automatically using the Organization ID you set on the connection — you don't need to replace it yourself.
    </Note>

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Tenklo in your app.

        To obtain your own credentials, follow the setup guide linked below.
    </Step>
</Steps>
