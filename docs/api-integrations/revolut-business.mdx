## 🚀 Quickstart

Connect to Revolut Business with Tenklo and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Revolut Business_.
    </Step>
    <Step id="authorize-revolut-business" title="Authorize Revolut Business">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_, choose your environment, then authorize. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-revolut-business-api" title="Call the Revolut Business API">
    Let's make your first request to the Revolut Business API (list your accounts). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/api/1.0/accounts" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/1.0/accounts',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Tenklo in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>

## API gotchas

- Sandbox and production are fully separate environments with different domains and certificates — a certificate uploaded in one won't work in the other.
