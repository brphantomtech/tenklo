## 🚀 Quickstart

Connect to Square Sandbox with Tenklo and see data flow in 2 minutes.

<Steps>
     <Step title="Create the integration">
    In Tenklo ([free signup](https://app.tenklo.dev)), go to [Integrations](https://app.tenklo.dev/dev/integrations) -> _Configure New Integration_ -> _Square Sandbox_.
    </Step>
    <Step title="Authorize Square">
    Go to [Connections](https://app.tenklo.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to Square Sandbox. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Square Sandbox API">
    Make your first request to the Square Sandbox API (e.g. list locations). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.tenklo.dev/dev/integrations), and [connection ID](https://app.tenklo.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.tenklo.dev/proxy/v2/locations" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Tenklo's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/locations',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.tenklo.dev/dev/logs) tab in Tenklo to inspect requests.
    </Step>

    <Step title="Implement Tenklo in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Tenklo in your app.

        Use **_squareup-sandbox_** for development and **_squareup_** for production in Tenklo.
    </Step>
</Steps>
